# calendarBuddy UI instructions

Follow [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) and the root [homeBuddy UI family contract](../../openspec/specs/homebuddy-ui-family/spec.md). Keep the shared shell, authentication, field, button, surface, and dialog anatomy aligned with finanzBuddy. Use the calendarBuddy indigo palette and the documented member color keys. Every control needs a visible label or accessible name, keyboard focus, and a narrow-screen layout. Run `npm run test`, `npm run lint`, and `npm run build` for UI changes.
